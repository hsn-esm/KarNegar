# کارنگار (KarNegar)

اپ اندروید شخصی برای ثبت و محاسبه‌ی ساعت کارکرد، با تقویم شمسی و قمری، خلاصه‌ی ماهانه و خروجی PDF و Excel.

همه‌ی داده‌ها روی خود گوشی و در حافظه‌ی داخلی اپ ذخیره می‌شوند. اپ **هیچ مجوزی** نمی‌گیرد، به اینترنت وصل نمی‌شود و هیچ حساب کاربری یا نقش مدیر ندارد؛ دقیقاً همان چیزی که برای استفاده‌ی شخصی هر کارمند لازم است.

## امکانات

- تقویم شمسی مینیمال با نمایش تاریخ قمری هر روز و تعطیلات رسمی شمسی و قمری (لیست آفلاین درون‌برنامه‌ای)
- تعطیلی دستی: نگه داشتن انگشت روی یک روز، وضعیت آن را بین «خودکار → تعطیل → کاری → خودکار» می‌چرخاند
- ثبت شیفت با یک ضربه روی روز، به‌علاوه‌ی کارت «ثبت امروز» برای ثبت زنده
- پنج شیفت: صبح ۰۷:۳۰–۱۵:۰۰، بعدازظهر ۱۵:۰۰–۲۱:۳۰، عصر ۰۷:۳۰–۱۸:۰۰، تعطیلی ۰۷:۳۰–۲۱:۳۰، شب ۲۱:۳۰–۰۷:۳۰ روز بعد
- محاسبه‌ی خودکار تعجیل/تاخیر در ورود و تعجیل/تاخیر در خروج
- خلاصه‌ی ماهانه: کل کارکرد و تفکیک هر شیفت، با جابه‌جایی بین ماه‌ها
- گزارش‌گیری جز‌به‌جز به PDF و XLSX، با نام کارمند در بالا-راست، ماه گزارش در وسط و تاریخ تولید خروجی در بالا-چپ
- تم روشن/تاریک/پیرو سیستم و نمایش نسخه‌ی اپ در تنظیمات

## گرفتن فایل APK از گیت‌هاب

اپ روی GitHub Actions ساخته می‌شود؛ لازم نیست چیزی روی کامپیوتر نصب کنید.

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (خصوصی هم باشد اشکالی ندارد).
2. محتویات همین پوشه‌ی `KarNegar` را در ریشه‌ی ریپازیتوری قرار دهید و push کنید:

   ```bash
   cd KarNegar
   git init
   git add .
   git commit -m "KarNegar 1.0.0"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```

3. در گیت‌هاب به تب **Actions** بروید. workflow با نام `Build KarNegar APK` به‌طور خودکار اجرا می‌شود. اگر اجرا نشد، از داخل همان تب دکمه‌ی **Run workflow** را بزنید.
4. پس از پایان اجرا (حدود ۵ تا ۱۰ دقیقه)، در صفحه‌ی همان run پایین‌تر بخش **Artifacts** را ببینید و `KarNegar-debug-apk` را دانلود کنید. فایل زیپ است؛ داخلش `app-debug.apk` قرار دارد.
5. APK را روی گوشی کپی و نصب کنید. برای نصب باید در تنظیمات اندروید «نصب از منابع نامشخص» برای برنامه‌ی مدیر فایل فعال باشد.

نکته: علاوه بر APK دیباگ، workflow خروجی release و نتیجه‌ی تست‌های واحد را هم آپلود می‌کند. APK ریلیز **امضا نشده** است، پس برای نصب معمولی همان نسخه‌ی دیباگ را بردارید.

## دیباگ و مشاهده‌ی خطاها

لاگ کامل هر مرحله در تب Actions، داخل همان run، قابل مشاهده است. اگر build شکست خورد، متن خطا در قدم `assembleDebug` نمایش داده می‌شود. برای اجرای مجدد بدون تغییر کد، دکمه‌ی **Re-run jobs** کافی است.

## باز کردن پروژه در Android Studio (اختیاری)

اگر بعداً خواستید پروژه را روی کامپیوتر باز کنید:

- فایل `gradle-wrapper.properties.txt` را به مسیر `gradle/wrapper/gradle-wrapper.properties` منتقل و نام آن را به همان `gradle-wrapper.properties` تغییر دهید، یا در Android Studio از منوی `File > Sync Project with Gradle Files` استفاده کنید تا wrapper خودش ساخته شود.
- به JDK 17 و Android SDK 34 نیاز دارید.

## ساختار پروژه

```
app/src/main/java/ir/karnegar/app/
├── MainActivity.kt            نقطه‌ی ورود، RTL و صفحه‌ی نام‌گیری اولیه
├── calendar/                  تبدیل شمسی/قمری و لیست تعطیلات
├── model/                     تعریف شیفت‌ها و موتور محاسبه‌ی ماهانه
├── data/                      ذخیره‌سازی محلی روی SharedPreferences
├── export/                    تولید PDF و XLSX و اشتراک‌گذاری فایل
└── ui/                        تم، اجزای مشترک و چهار صفحه‌ی اصلی
```

تست‌های واحد در `app/src/test/java/ir/karnegar/app/KarNegarTest.kt` صحت تبدیل تاریخ شمسی، محاسبه‌ی تعجیل/تاخیر و جمع‌بندی ماهانه را می‌سنجند.
